# IT Support Homelab

A beginner IT support homelab project focused on building practical troubleshooting, networking, and system administration skills.

## Project Goal

The goal of this project is to practise common entry-level IT support tasks using virtual machines, networking tools, and documentation.

## Lab Environment

- Host Machine: Windows PC
- Virtualisation: VirtualBox
- Virtual Machines:
  - Windows 10/11 VM
  - Ubuntu Linux VM

## Skills Practised

- Virtual machine setup
- Windows and Linux basics
- Network connectivity testing
- IP address checking
- Ping and traceroute commands
- DNS troubleshooting
- Software installation
- User support documentation
- Basic cybersecurity awareness

## Tools Used

- VirtualBox
- Windows
- Ubuntu Linux
- Command Prompt
- PowerShell
- Linux Terminal

## Planned Lab Tasks

### Lab 1: Virtual Machine Setup
Set up Windows and Ubuntu virtual machines using VirtualBox.

### Lab 2: Network Connectivity Testing
Use commands such as `ipconfig`, `ping`, `tracert`, and `nslookup` to test connectivity.

### Lab 3: Basic Windows Troubleshooting
Practise checking system information, installed programs, updates, and user account settings.

### Lab 4: Basic Linux Troubleshooting
Practise using terminal commands such as `pwd`, `ls`, `cd`, `ip a`, `ping`, and `sudo apt update`.

### Lab 5: Troubleshooting Documentation
Write simple support-style notes explaining the issue, steps taken, and resolution.

## What I Want to Learn

- How to troubleshoot common IT support issues
- How to document technical steps clearly
- How Windows and Linux systems behave in a basic network
- How to build confidence using technical tools
